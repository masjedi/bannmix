# BanMix Design System

## Brand Colors

| Color | Hex | Purpose |
|---|---|---|
| BanMix Blue | #2590C7 | Brand identity, navigation, links |
| BanMix Orange | #E86E2B | Ordering and conversion actions |
| BanMix Green | #0E6843 | Trust, production, quality |
| BanMix Dark | #20211A | Light-mode body text only |
| BanMix Navy | #071426 | Dark theme backgrounds, footer, premium sections |
| BanMix Cream | #FFF8EE | Warm food-brand backgrounds |

## Brand Hierarchy

Use:

```text
Orange → Action
Blue   → Identity
Green  → Trust
Dark   → Light-mode text
Cream  → Warmth
Navy   → Dark-mode surfaces
```

## Usage Notes

- Primary buttons and order CTAs: Orange
- Nav active states, links, brand marks: Blue
- Checkmarks, quality, made-in / production cues: Green
- Default light-mode text: Dark (`#20211A`) — never use as a dark-theme background
- Dark theme page/section/footer backgrounds: Navy (`#071426`) only
- Dark theme elevated cards: Navy base or `white/6%` overlay on navy — not brand-dark
- Hero/footer premium panels: Navy on white or cream accents
- Avoid purple gradients, generic AI cream/terracotta looks, brown/olive dark surfaces, or non-brand palettes
